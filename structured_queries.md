# Structured Queries — Day 4

Five SQL queries against `coverage.db` (tables: `plans`, `claims`), each mapped
to a realistic member question the coverage chatbot should be able to answer.

Database: SQLite (`coverage.db`)
Source data: `data/plans.csv`, `data/claims.csv` (synthetic, generated by `generate_data.py`, cleaned by `ingest.py`)

---

## Q1: "What are all my claims and their status?"

**Member question:** *"Can you show me the history of my claims?"*

```sql
SELECT c.claim_id, c.claim_date, c.service_type, c.billed_amount, c.approved_amount, c.status
FROM claims c
WHERE c.member_id = 'MBR0001'
ORDER BY c.claim_date;
```

Returns every claim for a given member, ordered chronologically, with billed vs.
approved amount and status.

---

## Q2: "What plan am I on and what's my deductible?"

**Member question:** *"What's my deductible and out-of-pocket max?"*

```sql
SELECT p.plan_name, p.tier, p.monthly_premium, p.deductible, p.out_of_pocket_max
FROM plans p
JOIN claims c ON c.plan_id = p.plan_id
WHERE c.member_id = 'MBR0002'
LIMIT 1;
```

Joins `claims` to `plans` to look up plan details for a member.

---

## Q3: "How many of my claims get approved vs. denied?"

**Member question:** *"How often do claims actually get approved?"*

```sql
SELECT status, COUNT(*) AS claim_count, ROUND(SUM(billed_amount),2) AS total_billed
FROM claims
GROUP BY status
ORDER BY claim_count DESC;
```

Aggregate view across all claims by status.

---

## Q4: "Which plan tier has the highest average claim cost?"

**Member question:** *"Is a Gold plan going to cost more in claims than Bronze?"*

```sql
SELECT p.tier, ROUND(AVG(c.billed_amount),2) AS avg_billed_amount, COUNT(*) AS num_claims
FROM claims c
JOIN plans p ON p.plan_id = c.plan_id
WHERE c.status = 'approved'
GROUP BY p.tier
ORDER BY avg_billed_amount DESC;
```

Compares average approved claim cost by plan tier.

---

## Q5: "Which members have multiple denied claims?" (nested/HAVING query)

**Member question (support/ops angle):** *"Flag members who might need help appealing repeated denials."*

```sql
SELECT member_id, COUNT(*) AS denied_claims, ROUND(SUM(billed_amount),2) AS total_denied_amount
FROM claims
WHERE status = 'denied'
GROUP BY member_id
HAVING COUNT(*) >= 2
ORDER BY denied_claims DESC;
```

Uses `WHERE` + `GROUP BY` + `HAVING` to find members with 2+ denied claims.

## Notes on data cleaning (done in `ingest.py`)

- Dropped exact duplicate rows in both `plans` and `claims`.
- Coerced numeric columns to proper numeric types.
- Filled missing `out_of_pocket_max` values with the column median.
- Dropped claims with missing `member_id` or `plan_id`.
- Normalized `status` casing (`Approved` / `APPROVED` / `approved` → `approved`).
- Left `approved_amount` null for denied/pending claims intentionally.
